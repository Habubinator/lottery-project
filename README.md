# Giveaway App

Telegram Mini App platform for giveaways: tickets and referrals, sponsor channels, TON wallets, withdrawals, admin tools, and background workers.

## Stack

Node.js, TypeScript, Express, Prisma, PostgreSQL, Redis, BullMQ, Telegram Bot API, TON, Swagger, PM2

## Setup

```bash
cp .env.example .env
npm install
npx prisma generate
npm run dev
```
